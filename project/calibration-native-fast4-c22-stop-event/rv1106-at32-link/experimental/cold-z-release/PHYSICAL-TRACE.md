Copy only the three runtime files (the C# tracer, its REPL and distinct launcher) into the matching relative paths of the separately backed-up calibration-cold-release-c1 profile after review and source freeze. ## Runtime

Launcher: rv1106-at32-link/experimental/cold-z-release/run_cold_release_fixture.sh; accepts only a fresh run name and refuses a different profile root. Settings are fixed inside. Matching inherited settings are accepted; conflicting settings are rejected, never silently overwritten. All Z fixture defaults are explicitly pinned and unknown Z_* settings are rejected. PASSIVE_MOTOR_TRACE=0; old RAM/register observer is never included. THERMAL_PROFILE=none, NATIVE_NOZZLE_HEATER=0; recovered passive nozzle NTC is 30 C, heater/fan unconnected (ADC 4004 is the known recovered curve operating point). Autobaud, scalar, legacy bootstrap, 1 us quantum, icount 0 retained. Legacy bootstrap duration comes from unchanged generator defaults. No source/age/lead guard, force/geometry/polarity or clock changes.

New model files: motor-renode/peripherals/PassivePhysicalStateTrace.cs and motor-renode/platforms/passive-physical-state-trace.repl. The existing shared-model copy mechanism must include these before startup. Attach after plant construction to the same TMR8 TriggerOutput, without replacing the plant receiver. Constructor subscribes only. Start writes a single initial snapshot. A high trigger samples when Z last-integration source time is at least .01 s later than prior sample; no assumption of 30 kHz. 6000 complete data rows maximum, each flushed; all excess due samples counted as drops. Decimated trigger edges are intentional and separately counted. Source regression/nonfinite values and I/O failures stop the stream and set errors. No memory/register/bus/driver/GPIO reads. Bridge boolean uses only the pure plant getter.

Existing physical getters checked in immutable source: GetAngleRadians/GetVelocityRadiansPerSecond read rotor properties; relative travel is angle*39/(2*pi) for X/Y and angle*8/(2*pi) for Z; last integration time reads last[a]; contact reaction computes unilateral spring/damping algebra without mutation; bridge getter reads the boolean array. GetContactTorqueNewtonMeters's downstream ContactTorque has no mutation or integration. The tracer never calls integration, ADC publishing, GPIO writes, torque setters or state setters. Timer source emits masterMode=2 Blink on update/repetition, and can emit enable edges for mode 1. Therefore native rate is configuration-dependent: final min/max positive source-trigger intervals and raw edge counts are measured rather than asserted. No native rate has been measured by this task.

CSV: runs/<name>/physical-state.csv. Header is exactly the first line of evidence/cpu-free-r2/physical.csv, no comment prefix. 24 fields: sequence, observation_time_s; for x,y,z: state_time_s, angle_rad, relative_mm, velocity_rad_s, contact_torque_nm, bridge_enabled; then z_bed_clearance_mm,z_compression_mm,z_contact_force_n,z_contact_nonzero. Booleans are 0/1. Sequence starts 0. Observation clock is motor machine elapsed virtual seconds; each state clock is the respective axis last integration time. Never substitute one for the other. Relative position is physical projection, not firmware coordinates. Bed clearance=z+10, compression=max(0,-10-z), minimum-bed force=max(0,Z torque)/(0.008/(2*pi)), contact_nonzero uses torque!=0 including opposite-stop contact. Positive Z increases clearance. Velocity mm/s is rad/s*8/(2*pi) for Z or *39/(2*pi) for X/Y. This conversion assumes exactly the frozen synthetic-functional minimum-bed fixture, not calibrated hardware.

Final: Stop then WriteStatus runs/<name>/physical-state-status.json (CreateNew). Status keys schema=cold-physical-v1, rows_written,dropped_rows,error_count,last_error,capacity_reached,stopped,trigger_edges,decimated_edges,min_observed_trigger_interval_s,max_observed_trigger_interval_s. min interval null means no positive interval measured. Missing final status, nonzero errors/drops, capacity reached, truncated/malformed CSV, mismatched rows or timestamps fail closed. Stop/Dispose is idempotent; Start is single-use. Status-write failure propagates; no final status is not success. A write failing after partial bytes is possible at the filesystem level; consumers must reject incomplete records and require final successful health.

Keep separate existing contact-transitions.csv and genuine nozzle/main z-probe edge streams. PassiveGpioEdgeTrace writes and flushes every edge immediately, header after a # comment: virtual_time_s,sequence,kind,label,pin,level. GPIO-local timestamps are not physical source timestamps. Probe lows alone do not mean release. Require clock/source-health correlation and no extra pulses, no unintended X/Y motion, zero force/compression and complete settling interval of at least .5 seconds, as the parent's reviewed acceptance policy specifies.

Final health envelope markers are emitted after global pause in the main final command sequence:
- COLD_PROBE_nozzle_BEGIN/END and COLD_PROBE_main_BEGIN/END: Enabled before Stop; Stop has no value; Enabled after Stop; RowsWritten; DroppedRows; EdgeCount; CapacityReached; LastError. Expected before true, after false, drops 0, capacity false, empty error and matching complete CSV row count.
- COLD_CONTACT_BEGIN/END: ContactTraceEnabled (already stopped, false); ContactRowsWritten; ContactDroppedRows; ContactLastError. Require drops 0, empty error and matching complete CSV rows.
Parse only completed monitor responses, never echoed commands. These are final observations, no new live monitor probes. Existing final generator later repeats edge Stop harmlessly.
